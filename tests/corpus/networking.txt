Networking basics
A router is a device that forwards data between networks.
A switch is a device that connects devices inside one network.
A firewall is a security system that filters traffic using rules.
DNS stands for Domain Name System and translates names to IP addresses.
DHCP is a protocol that gives devices an IP address automatically.

Protocol layers:
1. Application
2. Transport
3. Network
4. Link

TCP is a protocol that delivers data reliably and in order.
UDP is a protocol that sends data without checking that it arrived.
HTTPS uses encryption because plain HTTP can be read by anyone on the path.
Latency is the time a packet takes to travel from sender to receiver.
Bandwidth is the maximum amount of data that can be sent in one second.
Note: the next section covers wireless networks.
Summary
Switches work inside a network and routers connect networks.
