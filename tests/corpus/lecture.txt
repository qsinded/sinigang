What is an OS?
An operating system is software that manages hardware and software resources.
The OS was first developed in the 1950s at IBM.
Today we will discuss processes.
A process is a program that is currently running.
A thread is the smallest unit of execution within a process.
Scheduler: the part of the OS that decides which process runs next.
Kernel: the core of the OS that talks to the hardware.
Example: Windows, Linux and macOS are operating systems.
Tip: Windows, Linux and macOS are common examples.
